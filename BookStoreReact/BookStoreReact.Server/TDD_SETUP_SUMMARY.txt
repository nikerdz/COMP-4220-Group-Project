# TDD Setup - What Was Done

## Steps Taken:

### 1. Created Test Project
Command: dotnet new xunit -n BookStoreReact.Server.Tests -o Tests
Location: BookStoreReact.Server/Tests/
Result: Created xUnit test project for unit testing

### 2. Added Project Reference
Command: dotnet add reference ..\BookStoreReact.Server.csproj
Purpose: Allow tests to access Order models and DALOrder classes
Result: Tests can now import and test Server code
